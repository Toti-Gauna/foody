# Nota sobre estas referencias

Estas imágenes se generaron con la dirección anterior (glassmorphism y brasas naranja/rojo). La página «Eclipse para locales de comida» usa ahora la estética **Efemérides** de Eclipse (ver `docs/ROADMAP.md`, §5, y `docs/PROMPT-IMAGENES.md`).

Siguen sirviendo como referencia de:
- composición de vistas de producto, panel y carta;
- identidad propia de cada demo (Alba, Neón 21, Grano, Gelato Pop);
- uso de los personajes dentro de la interfaz.

No se usan literales: el glass y el fondo de brasas no pertenecen a la página de Eclipse.
